# Computer and browser access

- Never use full desktop or native computer control. Do not inspect, capture, or interact with the user's desktop, native apps, personal browser windows, or existing personal browser tabs through computer-use tools.
- Never ask the user for permission to enable or use full computer control.
- When browser access is needed, use only an agent-owned isolated or sandbox browser, such as the in-app browser. Do not use the user's personal Chrome, Edge, or other desktop browser.
- Prefer available connectors, APIs, command-line tools, and local repository contents. For pull request reviews, inspect the PR metadata, diff, base branch, and relevant local code through those tools whenever available.
- If a task cannot be completed with available connectors, APIs, local tools, or an isolated browser, explain the limitation without offering or requesting full computer control.
